## 摘要
多模态大语言模型在视频时间定位方面取得了快速进展，然而现实应用通常需要定位满足组合性时间与空间条件的每一个事件。现有基准存在不足：它们每个查询仅定位单个时刻，计数但不考虑时间条件，或将定位与计数视为不相干的任务。我们提出了面向长视频的条件多事件时间定位基准 CoMET-Bench，包含跨越五个真实世界领域的600个视频上的2789个查询，视频平均时长33.8分钟，每个查询由4个时间条件、3个空间条件以及一个专用的负查询子集构成。我们还提出了统一的评估协议，联合衡量计数、定位和负查询识别，包括一个新的 Rejection-F1 指标，以防止懒惰的“始终为空”模型进行无意义游戏。对一系列 MLLM、基于智能体的和专用于定位的方法进行基准测试表明，现有方法远未解决此任务。基于这些发现，我们提出了 CoMET-Agent，一个无需训练的智能体框架，将任务重新表述为结构化的搜索与聚合，仅通过结构推理就将 F1@0.5 比 GPT-5 提高了 6.1%。失败分析进一步揭示了三个开放方向：细粒度实体跟踪、位置均匀检索和因果事件配对。

## Abstract
Multimodal large language models have made rapid progress in video temporal grounding, yet real-world applications routinely require localizing every event that satisfies compositional temporal and spatial conditions. Existing benchmarks fall short: they localize only a single moment per query, count without temporal conditions, or treat grounding and counting as disjoint tasks. We introduce CoMET-Bench for Conditional Multi-Event Temporal Grounding in long-form video, comprising 2789 queries over 600 videos averaging 33.8 minutes across five real-world domains, with each query composed from 4 temporal conditions, 3 spatial conditions, and a dedicated negative-query subset. We further propose a unified evaluation protocol jointly measuring counting, grounding, and negative-query recognition, including a new Rejection-F1 metric that prevents trivial gaming by lazy "always-empty" models. Benchmarking a broad suite of MLLMs, agent-based, and grounding-specialized methods reveals that existing approaches remain far from solving this task. Building on these findings, we propose CoMET-Agent, a training-free agentic framework that reformulates the task as structured search-and-aggregate, improving F1@0.5 by 6.1% over GPT-5 purely through structural reasoning. Failure analysis further surfaces three open directions: fine-grained entity tracking, position-uniform retrieval, and causal event pairing.

## 1. 论文的核心问题与整体含义（研究动机和背景）

现有视频时间定位（VTG）基准与研究存在三大缺陷：
- **单事件局限**：大多数基准（如 Charades-STA、QVHighlights）每个查询仅定位一个最佳时刻，无法应对视频编辑、体育分析等需要枚举所有符合复杂时空条件事件的实际场景。
- **查询缺少复合条件**：计数基准（如 RepCount、Countix）只统计重复动作，不提时间条件（如“在A之后”、“同时发生”等）；视频理解基准（如 Video-MME、MLVU）虽有条件查询但答案多为选择题而非精确时间戳。
- **评估割裂**：定位、计数、负查询识别从未被统一评估，存在“始终为空”的作弊策略。

**论文目标**：提出首个同时涵盖**多事件定位**、**复合时空条件**与**负查询**的基准 CoMET-Bench，并设计无需训练的智能体框架 CoMET-Agent，将任务建模为结构化搜索-聚合问题。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
将条件多事件时间定位转化为对**视频时间图**的搜索-聚合过程，通过四个步骤实现端到端推理。

### 关键技术细节
**步骤1：视频自适应规划（Video Adaptive Planning）**
- Planner Agent 解析自然语言查询，若含显式时间窗口则截取子视频，并自适应选择超参数配置（粗/中/细粒度设置），用于后续图构建。

**步骤2：时间图构建（Temporal Graph Building）**
- **事件图**：用 DINOv2 提取帧特征 + 变化点检测（PELT）得到粗粒度事件节点，边权重结合语义相似度和时间衰减。
- **动作图**：对每个候选事件节点，用 RAFT 光流特征再次分段得到细粒度动作节点，继承边连接逻辑。
- Filter Agent 初期筛除无关事件节点。

**步骤3：迭代图验证（Iterative Graph-based Verification）**
- 每次迭代选取候选动作节点，扩展其邻域（K跳内边权>阈值）构成感知上下文。
- Verifier Agent 检查该上下文是否满足查询（空间+时间条件）。通过则生成记忆条目（文本摘要、时间戳、置信度）。
- **在线去重**：通过时序NMS避免同一事件的重复记录，保留置信度高的条目。

**步骤4：最终聚合（Final Aggregation）**
- 将所有验证过的节点（来自全局记忆库）送入 Aggregator Agent，汇总得到事件数量与精确定位区间。

### 关键公式与算法
- 边权重定义：`w(e_{i,j}) = (z_i·z_j)/(||z_i||·||z_j||) * exp(-|i-j|/σ)`，结合语义相似度与时间衰减。
- 迭代验证算法见Algorithm 1：核心循环包括采样候选节点、构建感知上下文、Verifier判定、在线去重。
- 评估指标新增Rejection-F1：负查询拒绝率与正查询覆盖率的调和平均，防止“始终为空”作弊。

## 3. 实验设计

### 数据集
- **CoMET-Bench**：600个长视频（平均33.8分钟），共2,789个查询，涵盖5个领域（体育、影视、生活记录、知识、监控）。73.4%为正查询，26.6%为负查询。
- 查询设计了4种时间条件（因果、顺序、同步、有界）和3种空间条件（静态、动态、身份），以及负属性。
- 额外在标准基准 Charades-STA 和 ActivityNet-Captions 上验证泛化性。

### 对比方法
- **通用视频MLLM**：GPT-5、Gemini 2.5 Pro、Gemini 3 Flash、LLaVA-Video、LLaVA-OV1.5、LongVILA-R1、MiMO-VL、InternVL3.5（8B/38B）、Eagle2.5、Qwen3-VL（8.3B/30B）。
- **智能体方法**：VideoMind、Vgent、T*、VideoARM。
- **时间定位专精方法**：TRACE、DisTime、TimeLens、LITA。
- **CoMET-Agent**：使用Qwen3-VL 8B或GPT-5或Gemini 3 Flash作为骨干，配合冻结DINOv2、RAFT、Qwen3-VL-Embedding。

### 评估指标
- 计数：MAE、OBO（误差≤1）、Pearson correlation。
- 定位（正查询）：mIoU、Recall@0.5、F1@0.5。
- 负查询：Rejection-F1、FPR（假阳性率）。

## 6. 论文的主要结论与发现

- 现有方法在 CoMET-Bench 上表现极差：最好模型（Gemini 3 Flash）的 F1@0.5 仅 14.6%，专用于定位的方法 F1@0.5 低于 5.4%，且负查询幻觉严重（FPR 多 > 90%）。
- **CoMET-Agent 显著提升**：将 GPT-5 的 F1@0.5 从 10.1% 提升至 16.2%，Gemini 3 Flash 从 14.6% 提升至 19.0%。收益集中在组合时间条件（顺序、同步、因果）和长视频场景。
- Rejection-F1 成功惩罚了“始终为空”模型（如 LLaVA-OV1.5 的 Rej.-F1 仅 9.3%）。
- 三个未解决的开放方向：细粒度实体跟踪、位置均匀检索、因果事件配对。

## 7. 优点

- **方法设计优雅**：CoMET-Agent 是无需训练的，完全基于冻结模型和预训练工具，却通过结构化搜索带来明显提升，显示框架设计的价值。
- **实验覆盖全面**：包含三个类别的方法，消融和泛化实验齐全，失败分析具体且有启发性。

## 8. 不足与局限

- **基准规模有限**：2,789 个查询相对于某些大规模数据集仍偏小，可能存在偏差。
