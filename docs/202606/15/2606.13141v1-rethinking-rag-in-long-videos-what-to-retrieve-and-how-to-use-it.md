## 摘要
检索增强生成正从文本扩展到长段第一人称视频，系统必须跨多种模态和时间粒度选择查询相关的片段。然而，VideoRAG的进展受到两个差距的限制：现有基准允许在无需视频的情况下回答查询，掩盖了检索错误；先前的方法对每个查询应用单一模态-粒度配置，忽略了片段级别的变异性。我们通过引入V-RAGBench（一个包含<查询，证据片段，答案>三元组的基准，能够忠实、解耦地评估检索和生成）和CARVE（一种简单方法，跨配置运行并行检索器，并采用片段自适应重排序来识别每个片段的获胜配置）来解决这两个问题。然后，每个片段在其检索期间选择的获胜配置下进入生成器，产生一种交错证据形式，其中片段级别的决策在两个阶段中传播。CARVE优于八个最新的VideoRAG基线，提供给生成器的片段交错使用了多种配置，而非共享单一配置，这是查询级方法无法实现的行为。

## Abstract
Retrieval-augmented generation is moving beyond text into long, egocentric video, where systems must select query-relevant chunks across multiple modalities and temporal granularities. Yet progress in VideoRAG is limited by two gaps: existing benchmarks allow queries to be answered without the video, obscuring retrieval errors, and prior methods apply a single modality-granularity configuration per query, ignoring chunk-level variability. We address both by introducing V-RAGBench, a benchmark of $\langle$query, evidence chunk, answer$\rangle$ triplets that enables faithful, decoupled evaluation of retrieval and generation, and CARVE, a simple method that runs parallel retrievers across configurations and employs chunk-adaptive reranking to identify the winning configuration for each chunk. Each chunk then enters the generator under its winning configuration selected during retrieval, yielding an interleaved evidence form where the chunk-level decision propagates across both stages. CARVE outperforms eight recent VideoRAG baselines, with the chunks supplied to the generator interleaving multiple configurations rather than sharing a single one, a behavior unattainable by query-level methods.

### 论文核心问题与整体含义

长视频的检索增强生成面临两大结构性障碍：
1.  **基准测试的不可靠性**：现有的视频问答基准允许仅凭文本或常识就能回答大部分问题，无需依赖视频内容。这导致即使系统检索到无关片段，仍可能给出正确答案，从而掩盖了**检索阶段的根本性缺陷**，无法对 RAG 系统中的检索和生成两个阶段进行独立、有效的评估。
2.  **方法论的粗粒度**：现有的 VideoRAG 方法在处理视频片段时，通常为整个查询选择一个固定的**模态-粒度**配置（如：仅依赖文本或仅依赖视觉特征，仅使用帧级或片段级表示）。这忽略了不同视频片段可能最适合不同表示方式的事实，导致检索和生成的效能受限。

### 论文提出的方法论

本文提出了一套系统性解决方案，包括一个专用的基准和一个新颖的方法。

#### 1. V-RAGBench 基准

-   **核心目标**：构建一个能够**解耦评估**检索和生成性能的基准，确保**回答必须依赖于检索到的视觉证据**。
-   **构建流程**：
    -   **数据源**：从 Ego4D 和 EgoLife 中选取 216 个时长超过1小时的第一人称长视频。
    -   **事件提取与去重**：利用核时序分割和聚类技术，将视频划分为语义独特、非重复的事件片段。
    -   **查询生成**：为每个事件片段，利用大语言模型生成锚定在该事件上的查询。
    -   **严格过滤**：通过五步过滤，确保生成的 2,100 个 <查询，证据片段，答案> 三元组强制满足三个关键属性：
        -   **视觉基础**：答案在纯文本和常识背景下无法得出。
        -   **证据定位**：答案无法从视频中的其他非证据片段推导出来。
        -   **证据非重复**：答案所依赖的事件在视频中唯一。

#### 2. CARVE 方法

-   **核心思想**：将模态（文本/视觉）和粒度（帧/片段）的决策权**下放到每个视频片段级别**，而不是固定在整个查询级别。
-   **技术细节**：
    -   **候选池并行构建 (Parallel Candidate Pooling)**：对每个查询，同时启动四个并行检索器，分别对应四种配置（文本-帧、文本-片段、视觉-帧、视觉-片段）。每个检索器返回其 top-k 片段，共同构成一个**携带配置标签的候选池**。
    -   **片段自适应重排序 (Chunk-Adaptive Reranking)**：利用一个多模态交叉编码器（如 Qwen3-VL-Reranker-2B），对候选池中的每个片段，**仅在其检索时的配置下**计算其与查询的相关性分数。
    -   **获胜配置确定**：对于出现在多个配置候选中的同一片段，保留其分数最高的那个配置作为其**获胜配置**。
    -   **交错生成 (Modality-Interleaved Generation)**：最终，只将各片段的获胜配置表示（而不是所有配置或一个固定配置）传递给生成器。生成器接收到的是一个“交错”的证据形式，不同片段以最适合它的方式呈现。

    **公式与算法流程（文字说明）**：
    1.  对于查询 `q`，并行执行四个 `top-k` 检索：`C_(m,g)(q)`，得到配置-片段标签对组成的池 `P(q)`。
    2.  对于 `P(q)`中的每个标签对 `(v, (m,g))`，使用交叉编码器计算重排分数 `s`。
    3.  对于每个片段 `v`，取其所有分数中的最高分对应的配置作为获胜配置 `(m*, g*)`。
    4.  最终，根据其获胜配置的分数对所有片段进行排序，得到最终 top-k 列表。
    5.  生成器根据 `q` 和每个片段 `v` 在其获胜配置 `(m*, g*)` 下的表示来生成答案。

### 论文的主要结论与发现

1.  **CARVE 性能卓越**：在 V-RAGBench 上，CARVE 在**检索和生成两个阶段**均显著优于所有 8 个基线。
    -   检索：Recall@5 达到 0.603，nDCG@5 达到 0.433（此前最佳为 0.510 和 0.340）。
    -   生成：在三个不同生成器上的通过率均最高（最高达 0.367）。
2.  **片段级决策优于查询级决策**：实验结果明确证明，不存在一个适用于所有片段的“最佳”配置。让每个片段选择自身最优的表示方式（即片段级决策）比为整个查询选择一个统一的配置（即查询级决策）效果要好得多。
3.  **配置分布具有多样性**：CARVE 的最终决策并非集中在单一配置上，而是**四种配置均被非平凡地选用**。这表明不同内容特性的片段确实需要不同的处理方式。
4.  **重排序策略是关键**：CARVE 的核心增益并非来自简单的重排序，而是来自“在检索时所使用的配置下进行重排序”这一特定策略。这确保了检索和重排序之间的对齐。
5.  **优势延伸至生成阶段**：将片段级别的获胜配置从检索阶段传播到生成阶段，带来的收益甚至超过了单纯提升检索质量本身。

### 优点

-   **方法设计新颖且合理**：将配置选择决策下放到**片段级别**是一个核心洞察，打破了以往“一刀切”的范式。
-   **基准构建严谨**：V-RAGBench 通过严格的过滤流程，有效解决了以往基准无法可靠衡量检索性能的根本性问题，为领域研究提供了更坚实的平台。
-   **解耦评估**：可以在 V-RAGBench 上独立分析检索和生成两个阶段的性能，从而更精准地诊断系统瓶颈。
-   **鲁棒性强**：CARVE 在多种生成器、不同数据集和不同配置下均表现出色，泛化能力强。
-   **效率高**：尽管使用了多个并行的检索器，但通过片段自适应重排序，模型仅在最终呈现给生成器时传递了最有效的表示，整体延迟（4.6s）甚至低于某些纯视觉检索方法（7.3s）。

### 不足与局限

1.  **配置空间有限**：本文仅探索了两种模态和两种粒度共四种配置。虽然能证明核心思想，但现实可能存在更多有效配置，如音频、知识图谱、元数据等。论文将此作为未来工作。
2.  **单次检索-生成流程**：论文仅研究了标准的单次检索-生成流程，未探索迭代式或智能体式的检索环路。文中承认，将 CARVE 的片段级决策融入这类更复杂的架构是未来的一个方向。
3.  **应用领域局限**：V-RAGBench 完全基于第一人称（egocentric）视频构建。虽然这对应了最具挑战性的应用场景，但方法论在其他视频类型（如纪录片、教学视频）上的有效性尚待验证。
4.  **资源消耗**：虽在效率上有优势，但 CARVE 需要为每个视频片段预计算四种不同配置的向量表示（离线），这本身是一种资源消耗。此外，使用 8 块 H200 进行实验，对计算资源的需求不低。
