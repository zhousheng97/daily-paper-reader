## 摘要
从真实世界演示中进行的机器人学习目前受限于数据规模。通用操作界面（UMI）提供了一种高效的无机器人数据收集接口，然而当前的UMI风格流水线往往收集冗余的演示，且缺乏全局场景上下文。为了提高数据效率，我们提出了EgoGuide，一种同步记录腕部和头部/自我中心观察，并将其与在线视觉-几何数据质量引导相结合的数据收集接口。我们还引入了一种门控自我中心残差策略，用于从视角变化的自我中心相机中进行鲁棒学习，使头部/自我中心上下文能够纠正模糊的局部观察，同时保持稳定的腕部视角控制。真实世界实验表明，EgoGuide减少了所需的数据段数量，并提高了数据效率。残差策略进一步提高了在视觉遮挡下的鲁棒性。项目页面：https://silicx.github.io/EgoGuide

## Abstract
Robot learning from real-world demonstrations is currently constrained by data scaling. Universal Manipulation Interface (UMI) provides an efficient robot-free data collection interface, yet current UMI-style pipelines often collect redundant demonstrations and lack global scene context. To improve data efficiency, we present EgoGuide, a collection interface that records synchronized wrist and head/egocentric observations and couples them with online visual-geometric data quality guidance. We also introduce a Gated Egocentric Residual Policy for robust learning from a viewpoint-varying egocentric camera, allowing head/egocentric context to correct ambiguous local observations while preserving stable wrist-view control. Real-world experiments show that EgoGuide reduces the required number of data episodes and improves data efficiency. The residual policy further improves robustness under visual occlusion. ## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：机器人学习受限于真实世界演示数据规模。通用操作界面（UMI）提供了一种低成本的免机器人数据收集方式，但现有UMI风格流水线存在两个关键瓶颈：
  - **数据冗余与缺乏多样性**：UMI使用手持夹爪代理收集数据，但演示者缺乏关于哪些状态已被覆盖或欠覆盖的反馈，导致收集的轨迹冗余，数据效率低（有时需要比遥操作多5倍以上的演示才能达到相当成功率）。
  - **缺乏全局场景上下文**：大多数UMI系统仅依赖单一腕部相机，在遮挡、物体消失或长时任务中，局部观察无法捕获完整任务状态。
- **目标**：提高UMI数据效率，通过在线收集时的覆盖引导和利用互补的自我中心（头部/自我中心）观察来解决上述瓶颈。

## 2. 论文提出的方法论
- **核心思想**：EgoGuide是一个集成的免机器人数据收集系统，包含硬件设计和在线数据质量引导；同时提出门控自我中心残差策略（GERP），在保持腕部视角稳定控制的同时，利用头部/自我中心上下文纠正局部模糊观察。
- **关键技术细节**：
  - **硬件设计（EgoGuide-UMI）**：
    - 手持夹爪接口：带旋转传感器测量夹爪宽度，通过树莓派控制；工业级鱼眼相机获取腕部图像。
    - 自我中心感知与空间追踪：Meta Quest头显提供头部相机图像和头部姿态，Quest控制器提供腕部姿态；AR透视视图提供全局上下文。
    - 同步无线传输：多模态数据通过UDP同步（头显72Hz，腕部20Hz），端到端延迟<100ms，交叉模态同步误差<20ms。
  - **在线数据策展**：
    - **在线数据覆盖引导**：在每次演示前，使用DINOv2和CLIP特征计算腕部图像、自我中心图像、腕部位姿的覆盖得分，通过与记忆库中的最近邻相似度转换为新颖性百分位，通过AR界面反馈给演示者，鼓励调整初始状态。
    - **部分演示**：支持从任务中间开始录制，增加后期状态覆盖。
    - **静态数据过滤**：后处理中根据模态缺失、长度、运动跳跃、模糊、亮度异常等规则拒绝不良片段（约2%-5%）。
  - **门控自我中心残差策略（GERP）**：
    - **阶段1：腕部基础策略**：训练标准腕部视角扩散策略，预测腕部相对动作（动作块）。
    - **阶段2：独立自我中心残差策略**：冻结基础策略，额外加入自我中心分支，以头部图像和腕部相对头部姿态为输入，预测残差动作候选和门控标量α。最终动作 = (1-α)*基础动作 + α*残差动作。
    - **训练目标**：同时使用流匹配损失和组合动作损失，采用课程调度（先单独训练残差分支，再逐渐引入组合损失）。
    - **部署**：使用固定的自我中心相机（无需主动控制头部），保持与训练一致的6D姿态。

## 3. 实验设计
- **任务与场景**：
  - 4个真实世界操作任务：Pick Cube（抓取立方体放盒）、Pepper Sorting（分类辣椒）、Garlic Storage（开启抽屉放蒜并关闭）、Rubik’s Cube（抓取并旋转魔方）。每个任务有子目标定义任务进度分数（TPS）。
  - **机器人部署**：Flexiv Rizon 4机器人 + Grav夹爪；腕部相机固定于末端，自我中心相机固定于工作空间（第三视角）。
  - **数据收集**：用户分别收集标准无引导数据和EgoGuide引导数据，每个数据集大小从100到400个演示不等，场景和光照匹配。
- **基准方法**：
  - 比较**有无EgoGuide引导**的腕部基础策略（π0.5）在不同数据规模下的表现。
  - 比较**GERP**与**Wrist Only**（标准UMI）、**Wrist+Ego Direct**（直接融合两视角输入）的性能。
  - 此外评估**部分演示**的效果、混合EgoGuide数据的比例实验、特征分布t-SNE可视化、不同固定自我中心相机位置的敏感性。
- **指标**：二元成功率（SR）和任务进度分数（TPS），每个策略20次试验，带有物体位置随机化。

## 4. 资源与算力
- **训练**：基于π0.5模型，使用4块NVIDIA H100 GPU和64核CPU。腕部基础策略训练30K步约5小时；GERP残差策略额外训练30K步约3小时。
- **评估**：使用单块NVIDIA RTX 4070 GPU和Intel i9-7900X CPU。
- **数据收集**：在线引导每样本平均增加4.3秒额外时间，但总体时间曲线仍然优于无引导收集。

## 5. 实验数量与充分性
- 实验数量较为充分：包含4个不同难度的任务，每个任务有多个数据规模（100-400演示），以及多种方法对比（有无引导、不同策略变体、部分演示、混合比例、相机位置敏感性）。还进行了特征可视化（t-SNE）和损失曲线分析。
- **充分性判断**：实验覆盖了主要动机（数据效率、遮挡鲁棒性），消融实验（部分演示、门控机制）合理，对比基准包括直接融合和基本UMI。但仅使用了单一机器人平台（Flexiv Rizon 4），未在多个机器人或跨领域验证泛化性。任务类型均为桌面操作，未涉及移动操作或更复杂场景。实验次数（20次/条件）足够，但未提供置信区间或统计显著性检验。

## 6. 主要结论与发现
- **EgoGuide引导显著提升数据效率**：在Pepper Sorting任务中，200个演示时成功率从10%提升至50%；使用一半数据即可达到无引导时的性能。混合EgoGuide数据持续提升效果。
- **部分演示增加数据覆盖**：后期状态分布更广，提升长时任务表现。
- **GERP优于直接融合自我中心视角**：在遮挡或收窄视觉场景下，GERP的门控机制保持腕部基础动作稳定，同时利用自我中心上下文; 在Pepper Sorting上达到80%成功率（Wrist+Ego Direct为65%）。
- **固定自我中心相机可行性**：GERP对不同相机位置鲁棒，而直接融合性能下降。
- **总体**：可靠的UMI扩展需要同时收集更信息丰富的演示和学习使用异构观察。

## 7. 优点
- **创新性**：首个在UMI收集过程中提供在线覆盖引导的工作，结合AR反馈给演示者，且支持从中间部分开始录制，提高数据多样性。
- **算法设计**：门控残差策略巧妙地将自我中心视角作为辅助而非替代，避免主动头部建模的复杂性，同时适应部署时固定相机设置。
- **硬件工程**：低成本、模块化，基于开源exUMI和商业AR头显，同步性能良好（<20ms）。
- **实验全面性**：从数据效率、策略鲁棒性、分布可视化等多角度验证，包含消融和敏感性分析。
- **实用性**：数据过滤规则简单有效，绕过学习型过滤器可能引入的偏差。
