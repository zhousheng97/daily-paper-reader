## 摘要
当一个多模态大语言模型正确回答了一个视觉推理问题时，其预测是否真的由任务关键性视觉证据支撑？正确答案可能与有缺陷的推理共存，因此仅凭准确性无法全面检验根基。我们引入了VisualFLIP，一个配对基准数据集，包含1,374张图像，按相同问题的扰动对排列，涵盖基数、属性、空间和逻辑任务。每一对保持问题不变，但最小程度地改变证据，使得正确答案确定性地翻转。我们使用配对准确率（要求同时解决一对中的两侧）和崩溃率（CR，衡量模型在至少解决一侧的情况下，对两张图像重复相同非空答案的频率）来评估24个MLLM。综合这些指标表明，配对正确性与证据依赖性既相关又不同：有能力的模型在任务关键性视觉变化后仍可能无法更新，并且在顺序设置中，当编辑后的图像跟随先前的答案时，某些模型的崩溃变得更严重。更多详情请参见我们的项目页面：https://didizhu-judy.github.io/VisualFLIP/

## Abstract
When a multimodal large language model answers a visual reasoning question correctly, is the prediction actually supported by the task-critical visual evidence? Correct answers can coexist with flawed reasoning, making accuracy alone an incomplete test of grounding. We introduce VisualFLIP, a paired benchmark with 1,374 images arranged as same-question perturbation pairs across cardinality, attribute, spatial, and logic tasks. Each pair keeps the question fixed but minimally changes the evidence so the gold answer deterministically flips. We evaluate 24 MLLMs with pair accuracy, which requires solving both sides of a pair, and Collapse Rate (CR), which measures how often a model that solves at least one side repeats the same non-empty answer for both images. Together, these metrics show that paired correctness and evidence dependence are related but distinct: capable models can still fail to update after task-critical visual changes, and collapse becomes more severe for some models when the edited image follows an earlier answer in a sequential setting. Further details are available on our project page: https://didizhu-judy.github.io/VisualFLIP/

### 1. 论文的核心问题与整体含义（研究动机和背景）

多模态大语言模型（MLLM）在视觉推理任务中能够给出正确答案，但这一答案是否真正依赖于图像中的**任务关键性视觉证据**？现有基准主要采用单图独立评估，正确答案可能源自语言先验、记忆模式或表面逻辑，而非对关键视觉变化的敏感响应。论文指出，准确性本身不足以衡量模型的视觉根基（grounding），亟需一种能够揭示预测对关键证据依赖性的评估方法。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：设计**配对图像扰动**，保持问题不变，仅最小程度改变任务关键性视觉证据，使得正确答案确定性地翻转。若模型的预测在证据变化后保持不变，则表明它没有真正依赖该证据。
- **关键技术细节**：
  - **VisualFLIP基准**：包含687对图像（1374张），涵盖四种扰动类别：基数（数量变化）、属性（颜色/数值等）、空间（位置/方向）、逻辑（规则/对应关系）。
  - **评估指标**：
    - **配对准确率**（Acc_p）：一对中两张图像都回答正确的比例。
    - **崩溃率**（CR）：在至少回答正确一张图像的对中，模型对两张图像给出相同非空答案的比例（式1，条件于 competence）。
  - **数据构建流程**：对于合成图像，通过编程模板生成；对于真实图像，先使用KL散度筛选不可从文本回答的样本，再用MLLM提取符号化证据，生成扰动计划，最后用图像生成器编辑。
  - **顺序评估**：让模型先回答原图，再在同一对话中回答编辑后的图像，测量原始答案的持久性（SeqCR）。
  - **探索性缓解方法——GMRL**：在GRPO基础上增加视觉必要性奖励，计算原始图像与局部掩码关键区域后的KL散度，用rank-transform规范化后加到准确率奖励中。

- **公式相关**：崩溃率CR = {i: c_io + c_ie ≥ 1 ∧ ŷ_io = ŷ_ie ≠ ∅} / {i: c_io + c_ie ≥ 1}。GMRL的视觉必要性奖励为D_{VN}(y) = Σ_t D_{KL}(π_θ(·|y_{<t}, v, q) || π_θ(·|y_{<t}, v_mask, q))。

### 6. 论文的主要结论与发现

- **高准确率≠低崩溃**：能力较强的模型（如GPT-5-mini）仍有可观崩溃率（27.6%），而Kimi K2.6虽然准确率中等但崩溃率极低（2.9%），表明两种指标刻画不同能力。
- **顺序环境加剧崩溃**：部分模型（如Qwen3.6-Plus）在顺序设置下SeqCR从6.8%飙升到39.2%，说明会话上下文使模型更倾向于坚持原答案。
- **任务类型调节崩溃**：路径追踪、连通性等空间和计数任务导致更高崩溃；编辑越显著（更大扰动），崩溃越低。
- **工具增强模型并未解决崩溃**：具备像素级操作能力的7B模型（如PixelReasoner）崩溃率仍高（51.6%），表明工具使用不自动转化为对证据变化的响应。
- **GMRL有改善趋势**：在Qwen2.5-VL-7B上，GMRL在属性、基数、空间类别上降低了CR，但逻辑类别效果不如GRPO，可能与掩码不覆盖规则证据有关。

### 7. 优点

- **新颖的评估范式**：将“答案是否随关键证据翻转”作为测试单元，比单图准确性更直接诊断视觉根基。
- **双指标设计**：配对准确率衡量基本能力，崩溃率衡量证据更新失败，两维互补。
- **多样化扰动类别**：覆盖计数、属性、空间、逻辑四种常见失败模式，有助于定位模型弱点。
- **顺序评估的导入**：揭示了会话上下文中的额外失效模式，实用性强。
- **开源基准**：687对图像数据公开，可复现。

### 8. 不足与局限

- **行为诊断而非机制性**：崩溃率高只能指出更新失败，无法区分原因（语言先验、感知错误、记忆偏差等）。
- **构建偏差风险**：真实图像使用了MLLM辅助筛选和编辑，可能引入与模型偏好相关的偏差；仅依赖人工检查，缺少感知差异量化指标。
- **任务类型不均衡**：真实图像部分任务类型的样本数有限（图6中空白表示<8个胜任对），导致某些类别结论统计效力低。
- **GMRL探索有限**：仅在一个骨干、一个种子下实验，未跨模型、多次运行；掩码仅限于物体级边界框，不覆盖逻辑规则类关键证据，致逻辑类别无效。
- **应用限制**：基准主要使用合成和图表图像，自然图像覆盖不足；不适用于评估内部推理忠实度，仅回答级结果。
