## 摘要
现有的手部检测算法基于图像工作，检测率受限于相机的帧率。在移动机器人系统的手部检测应用中，传统相机会导致运动模糊，尤其是在较暗的光照条件下。我们可以利用事件相机，它具有高动态范围、高时间分辨率和低功耗。最近的研究表明，使用事件相机和帧相机的立体设置可以提高检测精度及带宽-延迟权衡。在目标检测和识别任务中使用事件相机的主要瓶颈是训练数据相对较少。在这项工作中，我们提出了一种方法以及一个从自我中心的第一人称视角生成的示例性合成事件手部数据集。该数据利用v2e工具箱从现有的RGB Egohands数据集合成。通过改变v2e工具箱的参数，提供了不同光照条件和尺度的数据集版本。使用微调的YOLOv8模型生成真实检测结果，该模型应用于Egohands数据集中的RGB图像，并在高时间分辨率的事件上进行插值。我们使用该多模态数据集，结合现有的使用事件和RGB相机多模态设置的目标检测算法进行手部检测，并展示了与最先进水平相当的性能。

## Abstract
Existing hand detection algorithms work on images and the detection rate is restricted by the frame rate of the camera. In hand detection applications for moving robotic systems, conventional cameras cause motion blur, especially in darker lighting conditions. We can leverage the use of event-based cameras which possess a high dynamic range, high temporal resolution, and low power consumption. Recent work has shown that using a stereo setup of an event-based and a frame-based camera improves detection accuracy and the bandwidth-latency tradeoff. The main bottleneck in using event-based cameras in object detection and recognition tasks is a relatively low amount of training data. In this work, we propose a methodology and an exemplary synthetic event-based hand dataset from an egocentric, first-person view perspective. The data is synthesized from the existing RGB Egohands dataset with the v2e toolbox. Parameters of the v2e toolbox are varied to provide versions of the dataset with different lighting conditions and scales. Ground truth detections are generated with a fine-tuned YOLOv8 model which is applied to the RGB images in the Egohands dataset and interpolated on the high-temporal resolution events. We use the multi-modal dataset to perform hand detection with existing object detection algorithms which use a multi-modal setup of event and RGB cameras and demonstrate performance comparable to the state-of-the-art.

## 2. 方法论：核心思想、关键技术、算法流程

### 核心思想
利用成熟的RGB手部数据集 **Egohands**，通过 **v2e（Video-to-Events）工具箱** 模拟事件相机的物理行为，合成高时间分辨率的事件流，同时借助微调YOLOv8模型为全部视频帧生成手部边界框标签，从而获得**多模态、密集标注**的训练数据。

### 关键技术细节

1. **数据源**：Egohands数据集包含48段90秒视频（30fps，720×1280像素），每段仅标注100帧（约2.12%），共15,053个手部边界框。本文将其作为RGB输入。

2. **事件合成**（v2e工具箱）：
   - 利用SuperSloMo模型对视频进行**时域上采样**（`Upsampling Factor`参数），提升帧率以获得更高时间分辨率的事件。
   - 计算对数亮度变化，基于像素级阈值（ON/OFF）输出事件，模拟事件相机的**非理想性**（如阈值不均、有限带宽、漏电事件、散粒噪声等）。
   - 提供**Clean**（无噪声、高带宽）和**Noisy**（有限带宽、添加噪声）两套参数预设，生成不同版本数据集。

3. **标签生成与插值**：
   - 使用微调的**YOLOv8**模型对Egohands所有视频帧执行推理，生成每帧的手部边界框（合并左右手为单一“手”类）。
   - 由于事件流的时间分辨率远高于RGB帧，利用`timeidx`索引将边界框标签精确映射到事件流中每个33ms窗口的起始时刻。

4. **数据集版本**：
   - 表I给出6个版本（v1~v6），差异在于上采样因子（src→41倍）、尺度因子（1/2/4）、事件模型（Clean/Noisy/Mixed）。
   - 尺度因子4对应180×320px，适合快速训练；尺度因子1保留原分辨率。

5. **检测模型**：采用 **DAGr**——一种融合CNN（处理RGB帧）与异步图神经网络（处理事件流）的多模态目标检测器，事件以图结构表示（节点为事件，边缘由时空邻域构建），可保留稀疏性与高时间分辨率。

### 算法流程（文字描述）
1. 从Egohands读取RGB视频帧（30fps）及部分标注。
2. 用Fine-tuned YOLOv8对所有帧推理，得到每帧手部边界框标签。
3. 用v2e工具基于RGB视频生成同步事件流（微秒级），记录每帧对应的事件索引。
4. 将事件流切分为33ms窗口（对应30Hz标签频率），构建时空事件图。
5. 以RGB帧+33ms事件图为输入，训练DAGr模型（单类“手”，输出边界框）。
6. 在测试集上评估COCO指标（mAP@IoU0.5~0.95）。

### 偏差风险
- **伪标签引入噪声**：YOLOv8的检测错误（误检、漏检、边界框不准）会直接传播到事件标签，且未进行人工校验或质量过滤。

### 应用限制
- **计算开销**：DAGr模型需要同时处理RGB帧和事件图，推理速度可能不满足实时机器人需求（论文未提供推理延迟数据）。

- **泛化能力未验证**：无法保证在真实机器人搭载事件相机时取得类似性能。
