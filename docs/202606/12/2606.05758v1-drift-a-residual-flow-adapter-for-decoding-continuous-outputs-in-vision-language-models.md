## 摘要
许多现代视觉-语言模型（VLM）基于离散令牌的自回归解码。虽然基于文本的输出接口支持可扩展的预训练并在各种任务中展现出强大的零样本泛化能力，但它们并不适合需要精确连续输出的问题，例如定位事件的时间边界或生成机器人控制动作。为应对这一挑战，我们提出了DRIFT，一个用于将预训练VLM适应连续解码任务的通用框架。DRIFT将基础预测器（提供目标输出的粗略估计）与基于流匹配的生成式精化模块相结合，该模块迭代改进预测。这种残差形式将生成建模问题从学习全局输出分布转变为在强先验周围建模局部残差分布，从而显著简化优化过程。我们在感知和规划任务（包括视觉定位和机器人控制）上评估了DRIFT。跨越多种任务和架构（包括MLLM、VLA和WAM），DRIFT始终优于一组强大的基于回归和生成的解决方案。

## Abstract
Many modern vision-language models (VLMs) build on autoregressive decoding of discrete tokens. While text-based output interfaces enable scalable pretraining and strong zero-shot generalization across diverse tasks, they are poorly suited for problems that require precise continuous outputs, such as localizing temporal boundaries of events or generating robotic control actions. To address this challenge, we propose DRIFT, a general framework for adapting pretrained VLMs to continuous decoding tasks. DRIFT combines a base predictor, which provides a coarse estimate of the target output, with a generative refinement module based on flow matching that iteratively improves the prediction. This residual formulation transforms the generative modeling problem from learning a global output distribution to modeling a localized residual distribution around a strong prior, substantially simplifying optimization. We evaluate DRIFT on both perception and planning tasks, including visual grounding and robotic control. Across multiple tasks and architectures spanning MLLMs, VLAs, and WAMs, DRIFT consistently outperforms a strong set of regression- and generative-based solutions.

### 1. 论文的核心问题与整体含义（研究动机和背景）
现代视觉-语言模型（VLM）采用自回归离散 token 解码，在分类、描述等任务上表现出色，但难以直接输出**连续量**（如事件时间边界、机器人动作序列）。量化误差、丢失序结构和细粒度变化等问题使离散接口不适配连续预测。现有方法要么直接离散化/回归（确定性、无法建模多模态输出），要么使用扩散/流匹配纯生成（训练成本高、方差大）。DRIFT 提出将**确定性粗估计**与**生成式精炼**级联，形成一个通用、高效的残差适配器，使预训练 VLM 可适应连续解码任务。

### 2. 论文提出的方法论
- **核心思想**：基础预测器 \(g(z)\) 先从 VLM 隐状态 \(z\) 输出粗预测 \(\hat{y}\)；流匹配精炼模块 \(h_\theta\) 对残差 \(r = y - \hat{y}\) 进行迭代修正，最终输出 \(\bar{y} = \hat{y} + h_\theta\)。
- **关键技术细节**：
  - **线性插值桥**：\(y(t) = (1-t)(\sigma\epsilon + \hat{y}) + t y, \epsilon\sim\mathcal{N}(0,I)\)
  - **速度场参数化**：\(v_\theta(y(t),t,z) = [\alpha g(z) + (1-\alpha) h_\theta(y(t),t,z) - y(t)]/(1-t)\)
  - **损失函数**：标准流匹配 MSE（预测速度与真实速度 \(v^* = y - \sigma\epsilon - \hat{y}\)）
  - **联合训练**：当基础预测器不存在时，以 MLP 实现，额外加 MSE 损失 \(L_p\)，且在计算插值桥时对 \(g\) 使用梯度停止以防坍塌。
  - **推理**：\(y(0) = g(z) + \sigma\epsilon\)，用 10–20 步 ODE 求解到 \(y(1)\)；可多次采样平均降低偏差。
- **理论优势**：在固定基础预测器下，残差训练的目标信号和桥的方差更小，模型只需学习局部修正，优化更快、更稳定。

### 7. 优点
- **通用性**：框架与骨干无关，可适配 MLLM、VLA、WAM 等多种架构，且支持 tokenizer、MLP 等不同基础预测器。
- **高效性**：联合训练可同时提升基础预测器和精炼模块，比纯生成收敛更快、样本效率更高。
- **理论支撑**：提供定理证明残差桥方差更小、改进误差界，训练更稳定。
- **实用性强**：推理仅需少量 ODE 步数（K=10），且可通过多采样平均进一步降低偏差。
