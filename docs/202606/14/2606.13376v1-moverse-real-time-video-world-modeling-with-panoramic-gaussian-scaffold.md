## 摘要
我们提出了MoVerse，一个实时视频世界模型，能够从单张窄视场图像创建可交互导航的场景。这一设置具有挑战性，因为输入仅观察到环境的一小部分，而交互式漫游需要完整的周围世界、持久的几何结构、可控的相机运动以及时间一致的高保真观测。MoVerse通过将世界构建与观测渲染分离来解决这个问题。它首先利用拓扑感知扩散将输入扩展为重力对齐的360°全景图，在3D推理之前填补缺失的视场。然后，通过全景几何感知残差预测将全景图提升为持久的3D高斯支架，产生密集且可直接渲染的空间记忆。最后，一个高斯条件视频渲染器将沿用户指定相机轨迹的支架渲染转换为逼真的视频。为了使该渲染器适合交互，我们训练了一个双向扩散教师模型用于高质量条件渲染，并将其蒸馏为一个因果自回归学生模型用于有界延迟流式输出。这种设计结合了显式3D表示的可控性和长程一致性以及生成视频模型的感知质量。MoVerse在单个NVIDIA RTX 4090 GPU上支持8 FPS的实时场景漫游，展示了从单张图像创建具有交互式视频输出的世界的实用路径。

## Abstract
We present MoVerse, a real-time video world model that creates an interactively navigable scene from a single narrow-field-of-view image. This setting is challenging because the input observes only a small fraction of the environment, while interactive roaming requires a complete surrounding world, persistent geometry, controllable camera motion, and temporally coherent high-fidelity observations. MoVerse addresses this problem by separating world construction from observation rendering. It first expands the input into a gravity-aligned 360$^\circ$ panorama with topology-aware diffusion, closing the missing field of view before 3D reasoning. It then lifts the panorama into a persistent 3D Gaussian scaffold using panoramic geometry-aware residual prediction, yielding a dense and directly renderable spatial memory. Finally, a Gaussian-conditioned video renderer translates scaffold renderings along user-specified camera trajectories into photorealistic video. To make this renderer practical for interaction, we train a bidirectional diffusion teacher for high-quality conditional rendering and distill it into a causal autoregressive student for bounded-latency streaming. This design combines the controllability and long-range consistency of explicit 3D representations with the perceptual quality of generative video models. MoVerse supports real-time scene roaming at 8~FPS on a single NVIDIA RTX~4090 GPU, demonstrating a practical path toward single-image world creation with interactive video output.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：从**单张窄视场（NFOV）图像**生成一个**可交互漫游**的完整3D场景。输入只能观察到环境的一小部分，而交互式应用需要完整的周围世界、持久的几何结构、可控的相机运动以及时间一致的高保真观测。
- **现有方法局限**：
  - 显式3D方法（点云、网格、3DGS）可提供持久空间记忆和可控性，但单图重建时大部分区域需推断，容易出现空洞、浮点、深度错误，且感知质量有限。
  - 隐式视频/世界模型（如Genie、RTFM）可生成视觉较强的视频，但长程几何不稳定，容易出现漂移、身份改变或边界不连续。
  - 混合系统（显式几何+生成式渲染）虽结合了两者优势，但面临几何锚点的稀疏性与渲染器部署代价的权衡。
- **本文目标**：设计一种**三阶段分离**的实时视频世界模型，将“世界构建”与“观测渲染”解耦，既利用显式3D的可控性和持久性，又借助生成模型提升视觉质量，同时通过蒸馏实现低延迟流式输出。

## 2. 论文提出的方法论

### 核心思想
将过程拆分为三个顺序阶段，前两阶段离线构建可复用的3D高斯支架，第三阶段在线沿用户指定相机轨迹渲染高保真视频。核心设计是**用显式支架承载长程空间记忆，用生成式渲染器处理局部视觉增强**。

### 关键技术细节

- **Stage I：几何感知全景生成**（I → P）
  - **输入**：单张NFOV图像 I。
  - **输出**：重力对齐的360°等距柱状投影（ERP）全景图 P。
  - **步骤**：
    1. **重力校准**：通过可微自动调平模块，预测像素级对应场，经过刚性变换瓶颈（软argmin求解器）得到重力对齐的旋转，消除输入图像的倾斜和旋转。
    2. **拓扑感知补全**：使用**掩码潜在扩散模型**在潜在空间进行补全；采用**圆形潜在编码**使VAE的水平卷积边界环绕（wrap-around）；引入**平移等变一致性损失**（L_shift），使扩散过程对水平圆形偏移保持等变性，避免人工接缝。
  - **训练数据**：构建**Horizon360**数据集——对原始全景图进行重力规范化（将地平线对齐到ERP赤道），并采样透视视图（含不同偏航、俯仰、横滚、视场和宽高比）作为输入，偏航中心化后使输入位于全景中央。
  - **训练损失**：`L_stage1 = L_LDM + λ_shift L_shift + λ_flow L_flow`。

- **Stage II：全景高斯场景生成**（P → G）
  - **输入**：重力对齐的全景图 P 及其估计深度图 D。
  - **输出**：可直接渲染的3D高斯集合 G = {(μ_k, Σ_k, α_k, c_k)}。
  - **步骤**：
    1. **初始化**：在ERP网格上按步长选取像素，根据深度反向投影得到初始高斯中心 μ_k = D_k d_k；采用**纬度感知缩放** s_k ∝ D_k cos φ_k，以匹配ERP像素面积随纬度变小的特性。
    2. **深度引导残差预测**：提取多尺度图像特征，在**角-逆深度空间**（angular-inverse-depth space）预测残差参数 (Δθ, Δφ, Δz, Δs, Δq, Δc, Δα)，然后通过球面反向投影更新高斯中心，保持与ERP网格一致性和水平闭合性。
    3. **属性组合**：所有残差叠加到初始化值上，使用适当的激活函数（softplus、sigmoid等）保证参数有效范围。
  - **训练损失**：`L_GS = L_tgt + λ_src L_src + λ_depth L_depth + λ_Δ L_Δ`，包括目标视图重建损失（L1+LPIPS+SSIM）、源视图重建损失、逆深度损失以及残差正则化项（限制较大漂移）。

- **Stage III：高斯条件视频渲染**（V̂1:T → V1:T）
  - **输入**：沿用户指定相机轨迹从支架渲染得到的条件视频 **V̂1:T**（RGB流）和文本提示 τ。
  - **输出**：高保真视频 V1:T。
  - **步骤**：
    1. **双向条件教师模型**：初始化自 **Wan2.1-T2V-1.3B**，将条件帧潜在c与噪声目标潜在z_t沿通道拼接，两者使用**共享RoPE位置编码**，使模型将条件视为密集对齐的渲染指导。采用流匹配目标训练。
    2. **蒸馏为因果自回归学生**：将教师蒸馏为**因果自回归模型**，一次生成一个潜在块，使用**MemRoPE局部KV缓存**（1个sink帧、1个长期EMA记忆token、3个局部滑动窗口帧），保持短时连续性。蒸馏采用**Self Forcing**和**DMD**（分布匹配）原则，并引入**RAVEN**的变体以更好传递梯度。
    3. **推理时**：每4个像素帧为一个潜在块，2步去噪，使用**TAEHV解码器**加速，端到端达到8 FPS（RTX 4090）。

- **学生模型潜在漂移**：尽管支架保持长程一致性，但短期纹理漂移、过度平滑或延迟修正可能发生。
