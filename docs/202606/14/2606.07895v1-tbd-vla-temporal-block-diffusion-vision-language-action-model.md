## 摘要
离散视觉-语言-动作（VLA）模型通常将动作生成建模为离散动作空间上的下一个词元预测，每个词元自回归地依赖于先前上下文。虽然有效，但这种范式会产生高推理延迟，并且很大程度上忽略了动作轨迹中固有的时间结构。最近的工作引入并行解码以提高效率，实现更快的推理，但缺乏对词元依赖关系的显式建模。我们提出TBD-VLA，一种基于离散词元的VLA框架，它结合了块扩散以实现时间动作生成。我们将动作序列划分为时间块，并在每个块内执行掩码离散扩散，同时在块之间保持自回归生成。这种设计统一了时间自回归和并行动作解码，实现了强时间连贯性和更高的推理速度。此外，显式的时间建模使得通过时间修补可以异步执行动作块（例如实时分块）。TBD-VLA在仿真和真实世界操作任务上显著优于先前的VLA方法，为构建快速、时间感知的离散VLA模型提供了可扩展的路径。项目网页：https://tbd-vla.github.io/

## Abstract
Discrete Vision-Language-Action (VLA) models typically formulate action generation as next-token prediction over discretized action spaces, conditioning each token autoregressively on prior context. While effective, this paradigm incurs high inference latency and largely ignores the temporal structure inherent in action trajectories. Recent efforts introduce parallel decoding to improve efficiency, enabling faster inference, but lack explicit mechanisms for modeling token dependencies. We introduce TBD-VLA, a discrete token-based VLA framework that incorporates block diffusion to enable temporal action generation. We partition action sequences into temporal blocks and perform masked discrete diffusion within each block, while maintaining autoregressive generation across blocks. This design unifies temporal autoregression and parallel action decoding, achieving both strong temporal coherence and improved inference speed. In addition, the explicit temporal modeling enables asynchronous execution of action chunks (e.g., Real-Time Chunking) via temporal in-painting. TBD-VLA significantly outperforms prior VLA approaches in both simulation and real-world manipulation tasks, offering a scalable path toward fast, temporally aware, discrete VLA models. # 论文详细总结（TBD-VLA: Temporal Block Diffusion Vision Language Action Model）

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **动机**：现有离散视觉-语言-动作（VLA）模型（如 OpenVLA）通常通过自回归逐 token 预测来生成离散动作序列，导致两个核心问题：
  - **高推理延迟**：长动作序列的逐个 token 生成速度慢，难以满足高频闭环控制需求。
  - **忽视时序结构**：动作轨迹本身具有天然的时序依赖性，但自回归范式未显式利用块级（chunk-level）的时序关系。
- **背景**：近年工作尝试两种改进方向：（1）压缩动作表示以减少 token 数量（如 π0-FAST、VQ-VLA）；（2）并行解码加速（如 OpenVLA-OFT、离散扩散 VLA）。但现有方法或缺乏显式 token 依赖建模，或牺牲了时序连贯性。
- **总体目标**：提出一种融合**块级离散扩散**与**时序自回归**的 VLA 框架，在保持强时序一致性的同时实现快速推理，并支持异步执行（实时分块，RTC）。

## 2. 论文提出的方法论：核心思想与关键技术细节

- **核心思想**：将动作序列划分为**时间块**（temporal blocks），块内执行**掩码离散扩散**（masked discrete diffusion），块间保持**自回归生成**。这类似于语言模型中的“块扩散”（Block Diffusion）。
- **模型架构**：
  - **基础模型**：采用 Qwen3-VL 2B 作为 VLM 骨干，兼容其他 VLM。
  - **动作 tokenization**：将每个动作维度离散化为 512 个 bin，每个 bin 对应一个 action token。
  - **提示模板**：“State: {state tokens}, Task: {instruction}, Actions: {placeholder tokens}”。
- **训练流程**：
  - **时序级 token shift**：将预测目标从自重建改为“当前块预测下一个块”，对齐 VLM 的 next-token prediction 目标。
  - **离散块扩散**：前向过程对块内每个 token 独立采样掩码概率；反向过程在给定上下文（前序干净块 + 当前噪声块）下预测干净 token，损失仅计算被掩码位置的交叉熵。
  - **块级注意力掩码**：使用“双层布局技巧”（doubled-layout trick），将干净序列和噪声序列拼接并共享 RoPE 位置，在单次前向中同时处理多个块，大幅提升训练效率。
- **推理流程**：
  - **按需解码**：仅生成执行所需的块数（⌈Ha/m⌉），非全部预测块。
  - **前缀 KV Cache**：缓存视觉提词和已生成动作块的 KV 状态，避免冗余计算。
  - **动作解码策略**：采用**期望采样**（expectation sampling），即对每个动作维度的 token 分布求加权期望，而非取 argmax，实现更平滑的动作预测。
  - **实时分块（RTC）** ：异步机制，冻结前一部分动作块（对应推理延迟窗口）作为修补（inpainting）上下文，与训练中的部分掩码目标一致。

1. **性能优势**：TBD-VLA 在 LIBERO 上达到平均 97.7% 成功率，较 SOTA 提升；在 LIBERO-Plus 上平均 83.49%，优于次优方法 15.1%；在 SimplerEnv Google Robot 上达 91.0%（视觉匹配）和 86.3%（变体聚合）。

- **方法创新**：首次将块离散扩散引入 VLA，组合并行解码与时序自回归，优雅地解决了“效率 vs 时序建模”的 trade-off。
