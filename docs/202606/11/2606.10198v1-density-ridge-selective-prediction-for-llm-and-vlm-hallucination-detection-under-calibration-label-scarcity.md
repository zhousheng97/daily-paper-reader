## 摘要
大型语言模型和视觉语言模型中的幻觉检测越来越多地被构建为选择性预测问题，其中检测器会分配一个置信度分数，并在置信度较低时拒绝回答。无监督采样检测器（语义熵、特征分数）避免了标签需求但质量停滞不前，而监督探针（SAPLMA）虽然能在分布内获得更强分数，但在校准标签稀缺时性能急剧下降。我们将大语言模型的响应流形恢复为基于隐藏状态生成轨迹的六维运动学特征映射构建的核密度估计的密度脊。一个测试生成样本的得分是其特征投影点到最近脊顶点的负欧氏距离，从而得到随机输出分布的低维几何骨架。我们在七个问答基准测试（HaluEval-QA、TriviaQA、GSM8K、POPE、ScienceQA、A-OKVQA）上，使用九个文本和视觉大语言模型，在特意设计的标签稀缺协议（n_cal=200个查询，N=5个生成）下，与语义熵、SAR、特征分数、SAPLMA和对数概率进行了比较。我们的基于密度脊的得分在AUROC上取得了5-20个百分点的提升，同时在校准标签稀缺条件下显示出温和的性能下降。

## Abstract
Hallucination detection in large language and vision-language models is increasingly framed as selective prediction, where a detector assigns a confidence score and abstains when confidence is low. Unsupervised sampling detectors (Semantic Entropy, EigenScore) avoid labels but plateau in quality, while supervised probes (SAPLMA) attain stronger in-distribution scores yet degrade sharply when calibration labels are scarce. We recover the response manifold of an LLM as the density ridge of a kernel density estimate built on a six-dimensional kinematic feature map of hidden state generation trajectories. A test generation is scored by the negated Euclidean distance from its projected feature point to the nearest ridge vertex, yielding a low-dimensional geometric skeleton of the stochastic output distribution. We evaluate against Semantic Entropy, SAR, EigenScore, SAPLMA, and log-probability on seven QA benchmarks (HaluEval-QA, TriviaQA, GSM8K, POPE, ScienceQA, A-OKVQA) using nine text and vision LLMs in a deliberately label-scarce protocol ($n_{\text{cal}}{=}200$ queries, $N{=}5$ generations). Our ridge-based score beats on AUROC with 5-20 points gain, while demonstrating tempered degradation under calibration-label scarcity.

### 2. 论文提出的方法论：核心思想与关键技术细节

- **核心思想**：LLM多次采样同一查询时，隐藏状态轨迹在嵌入空间呈现多模态分布，其模式（modes）对应不同的响应策略。正确与错误的轨迹在“运动学特征空间”中具有不同的几何分布。本文提取轨迹的6维运动学特征，在正确样本上拟合核密度估计（KDE），并恢复其1维密度脊（ridge），以测试样本到脊的垂直距离作为幻觉置信度。

- **关键技术细节**：
  1. **运动学特征映射**（Kinematic feature map）：  
     给定隐藏状态轨迹 $H_{i,j} \in \mathbb{R}^{T_{i,j} \times D}$（最后层最后token的隐藏状态序列），计算：
     - 平均曲率 $K_n$
     - 曲率决定系数 $R^2$
     - 最大曲率 $K_{\max}$
     - 平均位移范数 $\|\Delta h\|$
     - 最大速度范数 $\|v\|_{\max}$
     - 归一化曲率峰值位置 $\tau^*$  
     共6维特征，记为 $x_m = \phi(H_m) \in \mathbb{R}^6$，并用训练集统计量做z-score标准化。

  2. **密度脊构造**：  
     在标注为正确的样本子集 $\tilde{X}^+$ 上拟合高斯KDE $\hat{p}$（带宽由Scott规则确定）。计算梯度 $\nabla \log \hat{p}$ 和Hessian矩阵的特征分解。定义1维密度脊为满足投影梯度为零且Hessian第5大特征值 $\lambda_5 < 0$ 的点集。使用子空间约束均值漂移（SCMS）迭代收敛到固定点集 $V=\{v_k\}$。通过TwoNN方法验证内在维度为1。

  3. **得分计算**：  
     对于测试查询 $q_*$ 的每个生成轨迹 $H_{*,j}$，将其特征点 $\tilde{x}_{*,j}$ 投影到距离最近脊顶点的垂直距离 $z_{\text{off}}(\tilde{x}_{*,j}) = \min_k \|\tilde{x}_{*,j} - v_k\|_2$，最终得分 $s(q_*) = -\frac{1}{N_*} \sum_j z_{\text{off}}(\tilde{x}_{*,j})$。负号使分数越高表示越可信。

  4. **脊坐标变体**（Table I）：三种将脊转换为坐标的方式：
     - Ridge LTSA Chart：全局LTSA降维
     - Ridge Arclength：沿脊图计算测地弧长
     - Ridge Atlas：局部分片图集拼接

### 6. 论文的主要结论与发现

1. **密度脊检测器在所有指标上全面超越基线**：AUROC提升5-20个百分点，AURC和AUGRC显著下降，尤其在多模态接地数据集（A-OKVQA、ScienceQA）上提升最大（如Idefics3从0.795升至0.972，SmolVLM从0.790升至0.990）。
2. **脊结构是核心因素**：所有SCMS变体均优于朴素几何基线（PC1、kNN、马氏距离），说明正确与错误轨迹的区分依赖于流形的形状而非位置。
3. **对标签稀缺稳健**：在校准标签仅200个时，性能退化速度慢于监督探针；脊分数与对数概率互补（在文本事实性上仍有4-6点AUROC盈余）。
4. **量化鲁棒**：在nf4量化下，脊-对数概率-非脊的排序保持不变。
