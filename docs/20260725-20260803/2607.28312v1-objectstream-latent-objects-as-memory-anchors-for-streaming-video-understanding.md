## 摘要
流式视频理解要求模型在未来的问题已知之前持续保留有用的视觉证据。现有方法主要根据令牌重要性、时间冗余或片段级相关性来管理不断增长的视觉上下文，但很少围绕随时间持续存在和演化的对象来组织证据。因此，在本文中，我们引入了ObjectStream，这是一种无需训练的框架，将潜在对象视为流式视频理解的内存锚点。ObjectStream直接从冻结的Video-LLM表示中归纳出空间连贯的潜在对象，将它们跨帧链接为持久锚点，并在有限的内存预算下维护它们的历史，无需外部对象检测器或分割模型。基于这些锚点，ObjectStream保留三种互补的证据形式：持久对象历史、瞬态对象变化和近期视觉上下文。这种设计使现有的视频大语言模型（Video-LLMs）能够在底层模型不变的情况下，对对象身份、交互和状态变化进行推理。在在线流式和离线长视频基准上的大量实验证明了其有效性和效率。在在线流式评估中，ObjectStream在OVO-Bench实时视觉感知上将Qwen2.5-VL-7B提升了10.0个百分点，同时将峰值GPU内存和TTFT降低了约50%。在离线长视频基准上，它在丢弃82.5%的视觉令牌的情况下超越了全令牌基线。这些结果凸显了潜在对象作为紧凑流式视频内存的一种实用且有效的组织原则。

## Abstract
Streaming video understanding requires models to continuously retain useful visual evidence before future questions are known. Existing approaches primarily manage the growing visual context according to token importance, temporal redundancy, or segment-level relevance, but rarely organize evidence around objects that persist and evolve over time. Thus, in this paper, we introduce ObjectStream, a training-free framework that treats latent objects as memory anchors for streaming video understanding. ObjectStream induces spatially coherent latent objects directly from frozen Video-LLM representations, links them across frames into persistent anchors, and maintains their histories under a bounded memory budget, without requiring external object detectors or segmentation models. Built on these anchors, ObjectStream preserves three complementary forms of evidence: persistent object histories, transient object changes, and recent visual context. This design enables existing Video Large Language Models (Video-LLMs) to reason over object identities, interactions, and state changes while leaving the underlying model unchanged. Extensive experiments on online streaming and offline long-video benchmarks demonstrate both effectiveness and efficiency. In online streaming evaluation, ObjectStream improves Qwen2.5-VL-7B by 10.0 points on OVO-Bench Real-Time Visual Perception, while reducing peak GPU mem-ory and TTFT by approximately 50%. On offline long-video benchmarks, it surpasses the full-token baseline while discarding 82.5% of visual tokens. These results highlight latent objects as a practical and effective organizing principle for compact streaming video memory.

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
- **ObjectStream**：一个**无需训练、即插即用**的视觉记忆框架，直接在冻结的 Video-LLM 视觉 token 表征上构建记忆，不修改底层模型、不依赖外部检测器或分割模型。
- 最终保留的记忆由三部分组成：
  - **持久对象历史**（Latent Object-Anchored Memory）
  - **瞬态对象变化**（Object-Conditioned Temporal Residuals）
  - **近期视觉上下文**（Recent Visual Grounding Window）

### 关键技术细节

#### S1：查询无关的 Token 显著性估计
- 对每帧先构造帧级上下文向量 `c_t`（对 patch token 做 ℓ2 归一化后求和再归一化）。
- 计算每个 token 与上下文向量的余弦不相似度作为显著性分数 `s_t,j`，分数越高越可能是前景对象。
- 通过帧内分位数阈值 `q` 选取活跃 token 集合 `A_t`（q 越大选得越少、越显著）。

#### S2：空间聚类发现潜在对象锚点
- 利用视觉 token 的 2D patch 网格结构，在活跃 token 上构建 4-连通图，然后通过连通分量找出空间连贯的对象候选区域 `C_t`。
- 使用显著性加权平均得到对象级特征 `μ = f(C_t,m)`（加权并归一化）。

#### S3：跨帧关联与有界对象集维护
- 维护动态对象集 `O = {O_i}`，每个对象轨道记录：对象特征 `μ_i`、最后观测时间 `τ_i`、时间一致性 `ρ_i`、对象显著性 `a_i`、历史 token 池 `T_i`。
- 对每个帧级候选：找到最相似的对象轨道（最大余弦相似度），若超过阈值 `θ` 则匹配并用 EMA 更新特征（公式8）；否则新建对象轨道。
- 对象集数量超过预算 `M` 时，按“最近观测时间 → 显著性 → 时间一致性”的字典序进行淘汰（公式9），保证记忆有界。

#### S4：对象中心证据保留
- 为每个保留的对象轨道，从其历史 token 池中按显著性选取 top-`k_i` 个代表 token，汇总为长期对象记忆 `R_object`（公式10）。
- 对象级分配容量，避免全局 top-k 被少数高突出区域主导。

#### Object-Conditioned Temporal Residuals（OCTR）
- 计算对象相邻两次匹配观测间的特征变化 `Δ_i,l`，使用对象自适应的阈值（均值 + 标准差，公式11）检测时序事件；
- 对检测到的突发变化事件，在事件时间戳附近局部窗口内按显著性选取额外原始 token，构成瞬态记忆 `R_temporal`（公式12），弥补 EMA 平滑对短时变化的抑制。

#### Recent Visual Grounding Window（RVGW）
- 直接保留最近 `L` 帧的原始视觉 token（公式13），支持“当前正在发生什么”等实时问题。

## 7. 优点

- **无需训练、无需修改模型**：即插即用，适配现有 Video-LLM，实用性强。
- **不依赖外部检测器/分割器**：对象直接从模型自身表征中涌现，保持了自包含性与可部署性。
- **对象中心记忆组织**：相比 token 级或片段级压缩，更能保留对象身份、跨帧轨迹与状态演变，符合流式长程推理需求。
- **互补的三类记忆**：长期对象历史 + 瞬态变化 + 近期 grounding，覆盖面广，兼顾长程语义与实时应答。
- **有界内存 + 对象级 token 配额**：记忆大小可控，避免全局 top-k 被少量高突出区域支配。
- **效率与性能同时提升**：大幅降低内存和首 token 延迟，同时取得更强推理性能。
- **跨场景泛化**：在线流式与离线长视频均验证有效，且在不同模型规模下趋势一致。
