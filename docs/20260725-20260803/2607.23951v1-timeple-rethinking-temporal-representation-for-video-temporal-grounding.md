## 摘要
视频时间定位（VTG）旨在定位由自然语言查询描述的连续视频区间。然而，当前基于VLM的方法通常通过两个端点输出间接产生该区间，表示为离散的时间戳标记或连续的边界坐标。这些表述在端点的编码方式上有所不同，但在预测内容上并无差异：事件区间仍然是派生对象，而区间有效性、持续时间和区间级相似性仅被隐式处理。我们提出TimePLE，通过预测有效时间区间上的单一联合分布，将VTG从端点预测重构为区间原生定位。TimePLE将每个区间映射到规范的位置-持续时间正方形中的一个点，其中每个支撑点对应一个有效的区间，相邻点代表几何上相似的区间。给定视频和查询，VLM生成一个单一的潜在<|TIMESPAN|>标记，其隐藏状态被解码为联合区间分布，通过持续时间感知的坐标校正进行细化，并转换为连续的边界。相同的区间表示用于编码输入的时间锚点，将视频侧的时间证据与输出侧的区间预测对齐。为了可靠地将潜在区间表示与完整的事件区间对齐，我们整理了90K规模的定位样本，并人工验证了3K规模的基准注释。在四个VTG基准上的实验表明，TimePLE始终优于端点预测基线，平均mIoU达到58.9，在短持续时间和中持续时间事件上取得了明显进展。

## Abstract
Video temporal grounding (VTG) aims to localize the continuous video interval described by a natural-language query. However, current VLM-based methods typically produce this interval indirectly through two endpoint outputs, represented either as discrete timestamp tokens or continuous boundary coordinates. These formulations differ in how endpoints are encoded, but not in what is predicted: the event interval remains a derived object, while interval validity, duration, and interval-level similarity are handled only implicitly. We propose TimePLE, which reformulates VTG from endpoint prediction to interval-native grounding by predicting a single joint distribution over valid temporal intervals. TimePLE maps each interval to a point in a canonical position-duration square, where every support point corresponds to a valid span and neighboring points represent geometrically similar intervals. Given a video and query, the VLM generates a single latent <|TIMESPAN|> token whose hidden state is decoded into a joint interval distribution, refined through duration-aware coordinate correction, and converted into continuous boundaries. The same interval representation is used to encode input temporal anchors, aligning video-side temporal evidence with output-side span prediction. To reliably align the latent span representation with complete event intervals, we curate 90K-scale grounded samples and human-verify 3K-scale benchmark annotations. Experiments across four VTG benchmarks show that TimePLE consistently outperforms endpoint prediction baselines, achieving an average mIoU of 58.9, with clear gains on short-duration and medium-duration events.

## 1. 论文的核心问题与整体含义（研究动机与背景）

视频时间定位（Video Temporal Grounding, VTG）是视频理解中的一项关键任务，其目标是在视频中定位由自然语言查询所描述的连续时间区间（如"狗跳起来接住绿色飞盘"对应的时间段）。该任务的监督信号与评估指标（如 mIoU）本质上是**区间级别**的——预测质量取决于预测区间与真实完整事件区间的时间重叠程度。

然而，当前基于视觉语言模型（VLM）的主流方法存在根本性错配：它们将 VTG 视为**端点预测**问题，即先预测开始和结束两个时间点，再间接推导出区间。

- 一类方法将时间表示为**离散文本时间戳**（textual timestamps）或符号时间标记（symbolic time tokens），沿用自回归语言接口，但标记级监督无法反映时间线远近，预测误差与实际定位质量脱节。
- 另一类方法引入**连续边界回归**（continuous boundary decoding），提供更平滑的监督，但本质上仍是端点中心式的预测对象——区间有效性需通过排序约束或后处理强制实施，区间时长只是两个坐标之差，区间级相似性并未在原生输出空间中被直接表示。

因此，离散与连续端点方法仅改变了端点的编码方式，**并未改变"预测什么"**：事件区间始终只是一个派生对象，而非模型的主要输出。TimePLE 正是为弥合这一任务目标与模型输出之间的鸿沟而提出，主张将 VTG 重构为**区间原生定位（interval-native grounding）**——直接预测有效时间区间上的联合分布。

## 2. 论文提出的方法论：核心思想与技术细节

### 2.1 核心思想：从端点预测到区间原生预测

TimePLE 的核心创新在于将 VTG 从"先预测两个端点、再组装区间"的范式转变为"**先预测区间、再解码边界**"的范式。论文将每个时间区间映射到规范位置–时长正方形（canonical position–duration square）中的一个点，在该空间中直接定义有效间隔上的联合概率分布。

### 2.2 关键技术细节

**（1）规范位置–时长正方形（Canonical Interval Square）**

对于归一化区间 I = [s, e]（0 ≤ s ≤ e ≤ 1），定义时长 d = e − s，映射函数为：

- **规范坐标**：C(I) = (u, v)，其中 v = d（时长坐标），u = s/(1 − d)（位置坐标，表示该时长下区间的可行相对放置位置）。对于全视频区间 [0, 1]，定义 C([0, 1]) = (0, 1)。
- **逆映射**：C⁻¹(u, v) = [u(1 − v), u(1 − v) + v]。

该映射将区间空间转化为单位正方形，**每个支撑点都对应一个有效时间区间**，且相邻点在几何上代表相似区间，保证了输出空间与可行区间空间的天然对齐。

**（2）软目标构造**

将正方形离散化为 Nᵤ × Nᵥ 网格，对任意连续规范坐标 c = (u, v)，沿位置轴和时长轴分别构造一维高斯分布，通过 softmax 归一化得到网格概率 pᵤᵢ 和 pᵥⱼ，其外积构成规范软目标 Φᵢⱼ(u, v)。

**（3）<|TIMESPAN|> 标记与区间解码**

- VLM 生成一个专门的潜在标记 <|TIMESPAN|>，其隐藏状态 h_span 经输出投影 A_out 和区间解码器 D_int，解码为网格上的联合区间分布 logits（Nᵤ × Nᵥ）。
- 通过**期望解码**（expectation decoding）——对网格概率取坐标期望——得到初始连续规范坐标 (û₀, v̂₀)，既保留了预测不确定性，又输出连续坐标。
- 进一步通过**时长感知坐标细化**（Duration-Aware Coordinate Refinement）修正离散化误差：门控值 g₀ 反比于预测时长（短区间分配更大的修正强度，并有上限约束），细化模块预测有界偏移 Δc，得到最终坐标并映射回连续时间边界。

**（4）时间锚点编码（输入侧）**

每个采样视觉单元的时间覆盖范围被表示为规范软密度，经区间编码器编码后，通过 <|TIMESTAMP|> 标记插入 VLM 输入序列。这使输入侧的视频时间证据与输出侧的区间预测共享同一套几何表示。

**（5）两阶段训练**

- **阶段一：区间几何训练**——在合成区间样本上（在均衡网格单元内采样规范坐标），单独训练区间编码器和解码器，仅优化区间重建目标（L_geo），不涉及 VLM。
- **阶段二：区间监督微调（Interval-Supervised SFT）**——在真实视频-查询数据上联合训练，优化标准自回归语言建模损失与共享区间目标（包括规范分布 CE 损失、IoU 重叠损失、边界 MAE 损失，且边界损失带有批量归一化的绝对时长权重），总损失为 LSFT = L_LM + λ_span · L_span。

**（6）数据整理与基准校正**

- **训练侧**：从公开 VTG 语料（InternVid、TimeLens、Ego4D、Charades-STA、ActivityNet-Captions 等）收集候选，利用 Qwen3-VL-30B 和 Gemini-3-Pro 两个异构教师 VLM 进行过滤（两模型预测均与原始标注达到 IoU 阈值才保留）和构造（两模型预测时间重叠且语义一致才接受），最终得到约 90K 规模的高质量训练样本。
- **评估侧**：通过模型辅助人工审核（Gemini-3-Pro 提供辅助预测和推理，人工在 Web 界面中判定 Keep/Modify Query/Modify Span/Delete）校正约 3K 规模的基准标注噪音。

## 6. 论文的主要结论与发现

1. **区间原生预测范式有效**：TimePLE 在四个基准上的平均 mIoU 达到 **58.9**，将 Qwen3-VL-8B 基线从 48.0 提升至 58.9（提升 10.9 个点），比匹配的 Timestamp-SFT 基线高 4.1 个点。
2. **短、中时长事件收益显著**：区间重叠对小误差更敏感的短（≤10s）和中（10–30s）时长事件上提升最大；长时间事件上仍具有竞争力，说明时长感知的区间预测不会牺牲粗粒度的时间定位。
3. **跨骨干一致提升**：三种骨干（0.5B/3B/8B）共 12 组骨干-基准比较中，TimePLE 全部优于 Timestamp-SFT 基线，平均提升分别为 +20.6、+0.9、+4.1 个点。
4. **表示层面差异显著**：归因分析显示，端点预测依赖时间上分离的边界线索，而位置与时长预测在整个目标时刻获得连贯的证据支持；区间似然景观上，TimePLE 的分布集中在目标区间附近且全部处于有效区间空间内，而文本时间戳的区间景观弥散且碎片化。
5. **SFT 是主要增益来源**：训练阶段消融表明，TimePLE 的收益主要来自区间监督 SFT 对 span 标记表示与规范区间空间的直接对齐；一旦对齐完成，结果级 GRPO 或更复杂的后训练目标（CSDO、TR-SPD）均无法提供额外增益。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练时长等关键资源信息，影响可复现性与成本评估。
- **依赖教师模型质量**：训练数据整理依赖两个教师 VLM（Qwen3-VL-30B、Gemini-3-Pro）的预测一致性来过滤和构造样本，教师模型的系统性偏差可能被继承到训练数据中；90K 规模相较 VTG 数据规模庞大的任务而言仍属中量级。
- **人工验证规模有限**：3K 规模的人工校正仅涉及 Charades-TimePLE 基准，未扩展到其他基准；人工校正的评判者间一致性（inter-annotator agreement）未报告。
- **主干模型覆盖面有限**：主结果仅基于 Qwen3-VL-8B；最弱骨干（LLaVA-OV-0.5B）上提升巨大但绝对性能仍偏低，而较强的 Qwen 骨干上提升较小（如 Qwen2.5-VL-3B 仅 +0.9），说明收益与骨干的预训练强度和语言先验有关，这一规律的更深层原因未充分探讨。
- **后训练扩展空间受限**：GRPO、CSDO、TR-SPD 均无增益，论文将此归因于 SFT 已实现充分对齐，但未排除实现细节、超参数调试不足或奖励设计欠优等因素；缺乏与更强后训练方法（如更细粒度的区间级奖励、外部教师分布蒸馏）的进一步对比。
- **网格离散化与细化依赖**：128² 网格 + 时长感知细化仍是一种近似连续化的方案，其性能受网格分辨率（2.25× 计算开销仅带来边际增益）和细化门控超参数（κ_cap、α、σ）影响，存在过拟合于合成区间重建分析的可能。
- **应用场景局限**：评估集中于英语查询与室内活动/日常事件类视频，对开放域、长视频、多事件纠缠场景的泛化能力尚未验证；区间预测范式假设事件为单体连贯区间，对离散多段事件的处理能力有限。
