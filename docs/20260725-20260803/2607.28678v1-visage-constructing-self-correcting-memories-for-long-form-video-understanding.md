## 摘要
在长时程环境中运行的多模态智能体必须构建并持续更新多媒体记忆，以支持实体一致、时间 grounded 的推理。然而，现有的智能体记忆方法在激进压缩和分段处理下常常丢弃细粒度的身份线索。它们还严重依赖向量相似性检索，这可能会浮现语义相关但身份不匹配的证据，导致实体混淆、错误传播和幻觉答案。我们提出 ViSAGE，一种多模态智能体记忆框架，构建自校正、以实体为中心的记忆。具体来说，ViSAGE 通过跨模态绑定在长时间范围内锚定实体身份。然后应用双向记忆精炼来传播延迟的身份证据，回溯性地统一历史记录并改善未来推理。我们还引入多智能体交叉验证，在身份-证据对齐约束下评估检索到的证据，使得在证据缺失时能够弃权而非给出无依据的答案。大量结果表明，ViSAGE 持续优于最强基线，准确率提高了 5.9%。

## Abstract
Multimodal agents operating in long-horizon environments must build and continually update multimedia memories to support entity-consistent, temporally grounded reasoning. However, existing agentic memory approaches often discard fine-grained dentity cues under aggressive compression and segment-wise processing. They also rely heavily on vector similarity retrieval, which can surface semantically related yet identity-mismatched evidence, leading to entity confusion, error propagation, and hallucinated answers.   We propose ViSAGE, a multimodal agentic memory framework that constructs self-correcting, entity-centric memories. Specifically, ViSAGE anchors entity identity via cross-modal binding over long temporal ranges. It then applies bidirectional memory refinement to propagate delayed identity evidence, retroactively unifying historical records and improving future reasoning. We also introduce multi-agent cross-verification to assess retrieved evidence under an identity-evidence alignment onstraint, enabling abstention instead of unsupported answers when evidence is missing. Extensive results demonstrate that ViSAGE consistently outperforms the strongest baseline, achieving 5.9% higher accuracy.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：多模态大语言模型（MLLMs）的快速发展使智能体具备处理视频、音频与语言的能力。然而，在长时程（long-horizon）任务中，智能体必须在超出单次上下文窗口的情况下持续构建和更新多媒体记忆。
- **核心痛点**：论文指出现有智能体记忆系统存在三大缺陷：
  - **时空细节丢失（Spatio-Temporal Detail Loss）**：为处理超长视频，现有方法常采用激进压缩或降采样，导致细粒度身份线索（如人脸、动作微动态）被抹除，实体消歧困难。
  - **分段处理困境（Segmentation Dilemma）**：多数管线将长视频切成独立片段处理，身份证据往往在后续片段中才出现，但分段式处理无法回改早期记忆，导致身份信息无法前向补偿。
  - **相似性—真实性鸿沟（Similarity–Veracity Gap）**：基于向量相似度的检索会把"语义相关但身份不匹配"的证据当作正确答案返回，缺乏验证机制，易产生实体混淆与幻觉。
- **整体含义**：论文主张长视频理解需要从"顺序处理"转向"自校正记忆架构"，即允许智能体在获得新身份证据后**回溯修正历史记忆**，实现实体一致、证据可验证的长期推理。

## 2. 方法论：核心思想与关键技术细节

- **总体架构**：ViSAGE 是一个三阶段多模态智能体记忆框架，维护双结构记忆库：
  - **Incident Logs（事件日志）**：按时间顺序记录"发生了什么"，包括时间戳、动作、对话等，事件内容不可变，但"谁做的"（who 字段）可被回溯修正。
  - **Object Cards（对象卡片）**：持续更新实体知识档案，汇总人物的身份属性、偏好、关系等，随新证据动态演化。

- **Part A：实体锚定预处理（Entity-Anchored Preprocessing）**
  - **序列级实体锚定（Sequence-Level Entity Anchoring）**：不依赖逐帧身份判定，而是先在整段视频上做多目标跟踪，获取长程人物轨迹；对每条轨迹选出质量最高的人脸作为原型（prototype），其余残缺/退化的人脸观测与原型匹配后统一分配同一实体 ID，形成稳定身份簇。
  - **说话人绑定（Speaker Binding）**：借鉴 McGurk 效应（视觉可以帮助消解音频歧义），提出双准则验证（Dual-Criteria Validation）：
    - 在高帧率流上运行 Active Speaker Detection（ASD），获取嘴型/音画同步证据；
    - 结合语音嵌入的声学匹配；
    - 当语音相似度足够高或 ASD 确认音画同步时，将 Voice_ID 绑定到 Face_ID，否则说话人保持未指派状态。

- **Part B：双向记忆精炼（Bidirectional Memory Refinement）**
  - **前向锚定（Forward Grounding）**：生成当前片段记忆时，用已确定的 Face_ID 从 Incident Logs（获取叙事连续性）和 Object Cards（获取角色一致性）检索双源记忆，引导 MLLM 将当前片段理解为叙事延续而非孤立片段。
  - **后向修正（Backward Rectification）**：当 LLM 由对话内容（如"Hey, Mario!"）推断出某个匿名视觉主体的身份时，生成等价信号（ID_sem ≡ ID_vis），触发全局回溯更新：遍历历史 Incident Logs，将之前所有匿名 ID 替换为已解析身份，统一角色历史记录。
  - **与 A-Mem、Optimus-1 的区别**：ViSAGE 的修正是**证据驱动**的，即只有发现明确身份证据时才触发，且直接改写过历史记录内容，而非仅仅建立语义关联。

- **Part C：认知裁决（Epistemic Adjudication）**
  - **身份解析调度器（Dispatcher）**：处理 ASR 噪声（如"Mario"被误识别为"Malloy"），利用已索引的合法角色名册，用 LLM 逻辑推理将噪声查询实体映射到正确实体，只激活相关的角色 Agent。
  - **人设驱动的证据检索（Persona-Driven Agents）**：
    - Scene Agent：从 Incident Logs 回答事实性、时间性问题（如"谁先站起来的"）；
    - Character Agent：从 Object Cards 回答静态属性问题（如"Lily 的职业"）。
  - **裁判 Agent（Judge Agent）**：最终仲裁者，对检索到的证据从贡献度、充分性和一致性三方面评估。如果两个记忆源都缺乏有效证据，或证据存在不可调和冲突，则触发**验证性认知拒答（Verified Epistemic Refusal）**——明确回答"不知道"，而不是编造答案。

## 6. 主要结论与发现

- ViSAGE 在三个基准上均取得最优结果：M3-Bench-robot 45.5%、M3-Bench-web 58.4%、Video-MME-long 79.1%，较最强基线（Gemini-3-Pro）**整体提升 5.9 个百分点**。
- **跨模态（CM）任务是最大突破**：ViSAGE 在 robot 上比 M3-Agent 高 15.9%，在 web 上高 27.1%，证明实体锚定机制有效解决了信号退化问题。
- 消融显示 **Bidirectional Refinement 贡献最大**（移除后 robot 下降 4.7%），说明回溯性身份修正是解决分段困境的关键。
- 框架具有**模型无关性**：从 Qwen3-VL-30b（42.1%）到 GPT-5（44.5%）再到 Gemini-3-Pro（45.5%），ViSAGE 均稳定提升基础模型能力。
- 安全性与可靠性显著改善：通过"验证性拒答"机制，系统将危险幻觉转化为诚实的不确定表达，更符合高 stakes 场景（如机器人）的部署要求。

## 7. 优点

- **范式创新**：提出"自校正记忆"概念，将记忆分为不可变的事件日志与可更新的实体卡片，实现**回溯统一身份**而不破坏历史记录，这是对传统 append-only 记忆体系的重要突破。
- **跨模态绑定设计的巧妙性**：将 McGurk 效应引入人机记忆系统，用视觉唇动同步（ASD）消解音频歧义，逻辑自然且有理论支撑。
- **严格证据驱动的修正**：与 A-Mem 的语义驱动修正、Optimus-1 的累积式记忆不同，ViSAGE 只有在发现明确身份证据时才重写历史，避免了级联错误。
- **可解释的推理链**：场景 Agent 与角色 Agent 分工明确，裁判 Agent 对证据做贡献度/一致性检验，形成清晰透明的推理链条，而非端到端黑箱。
- **效率与性能兼顾**：通过序列级实体锚定允许激进降采样（0.5 fps），在超越 M3-Agent 精度的同时，延迟还低 36%。
- **安全设计领先**：明确区分"危险幻觉"与"安全拒答"，以"知道不知道"作为系统考核指标，在具身 AI 场景中具有很高的实用价值。

## 8. 不足与局限

- **感知范围局限（最主要）**：Entity-Anchored Preprocessing 仅针对人类实体（Face_ID + Speaker_ID），非人实体（物体、动物）被当作背景，无法主动建档跟踪。作者承认这是未来工作方向（引入开放词表目标追踪与重识别）。
- **依赖现成感知工具**：人脸识别、语音嵌入、活动说话人检测等第三方工具的质量上限直接制约系统表现，在严重遮挡、多人密集、声学相似等极端条件下可能失效。
- **适用场景偏窄**：评测数据集集中于人物驱动的视频（机器人第一视角、纪录片/电影），对纯视觉事件（无人物）、非社交类视频的泛化能力未验证。
- **拒答机制的可用性权衡**：在证据缺失时强制拒答虽保证安全，但在实际应用中可能降低任务完成率；论文未讨论"证据不完整但可部分回答"的渐进式应对策略。
- **成本与延迟分析的完整性不足**：而仅比较 LLM 阶段的 token 和时间，未包含感知工具（跟踪/ASD）的端到端全流程开销，也未报告硬件配置。
