## 摘要
长视频理解日益依赖于大型视觉语言模型和工具增强推理，但大多数系统无论难度如何，都对每个示例应用相同的推理流程。这种统一策略对于简单问题会调用不必要的工具辅助处理，而在困难问题需要细粒度时间证据时却提供的控制有限。我们提出了CADER（置信度感知动态证据推理），一种无需训练的自适应且可靠的长视频推理框架。CADER首先对均匀采样的帧进行全局推理，并通过logit差值信号估算答案置信度，使高置信度示例能够提前退出。对于不确定的示例，CADER激活第二阶段的工具增强循环，该循环结合时间裁剪、轻量级语义验证和相关性引导的重采样，逐步定位与问题相关的证据。这种设计将工具使用视为样本级决策：一次全局处理处理简单情况，而额外的推理保留给不确定性表明需要更多证据的示例。在多个VideoQA基准上的实验表明，CADER在改进长视频推理的同时，对高置信度样本绕过第二阶段。此外，当应用于仅使用无工具思维链监督训练的骨干模型时，CADER实现了与专门工具增强框架相当的竞争性能，为自适应长视频推理提供了一条实用的推理时路径。

## Abstract
Long-video understanding increasingly relies on large vision-language models and tool-augmented reasoning, but most systems apply the same inference procedure to every example regardless of difficulty. This uniform strategy invokes unnecessary tool-assisted processing for easy questions and provides limited control when difficult questions require fine-grained temporal evidence. We propose CADER (Confidence-Aware Dynamic Evidence Reasoning), a training-free framework for adaptive and reliable long-video reasoning. CADER first performs global reasoning over uniformly sampled frames and estimates answer confidence with a logit-margin signal, allowing high-confidence examples to exit early. For uncertain examples, CADER activates a second-stage tool-augmented loop that combines temporal cropping, lightweight semantic verification, and Relevance-Guided Resampling to progressively localize question-relevant evidence. This design treats tool use as a sample-level decision: a single global pass handles easy cases, while additional reasoning is reserved for examples where uncertainty suggests that more evidence is needed. Experiments on multiple VideoQA benchmarks show that CADER improves long-video reasoning while bypassing Stage~2 for high-confidence samples. Moreover, when applied to a backbone trained only with tool-free chain-of-thought supervision, CADER achieves competitive performance against specialized tool-augmented frameworks, suggesting a practical inference-time route for adaptive long-video reasoning.

### 研究动机与背景

- 长视频问答（Long-Video QA）要求模型在长时间跨度中整合稀疏证据，并将自然语言查询与时间上分布式的视觉事件对齐，是长视频理解（LVU）的核心测试场景。
- 近期方法大量采用工具增强（tool-augmented）或智能体式推理，通过迭代调用工具来提升复杂查询的性能，但普遍存在一个关键设计缺陷：**对所有样本应用固定统一的推理流程**，隐式地认为每个问题都需要细粒度的时间搜索。
- 长视频基准本身具有混合的难度分布：许多问题仅凭全局视频语义即可回答，只有少数子集需要局部证据与迭代精化。因此，**统一调用工具会对简单样本引入大量冗余计算，甚至带来不必要的定位错误**。
- 另一个问题是：对难题而言“更多计算”并不必然等于“更好结果”——迭代推理中可能累积 grounding 错误或引入无关证据，反而破坏预测稳定性。
- 据此，论文提出一个核心命题：**工具调用应被建模为一种置信度条件化的、样本级的决策，而非默认流程**。

## 2. 论文提出的方法论

### 核心思想

CADER 是一个 **无需训练（training-free）** 的自适应长视频推理框架，核心思想是通过两阶段机制按样本难度动态分配计算资源：

- **Stage 1（全局初步推理）**：对均匀采样帧做全局推理并估计置信度，高置信度样本提前退出（early exit）。
- **Stage 2（工具增强细粒度推理）**：仅对低置信度样本激活，通过时间裁剪、语义验证、反射搜索和相关性引导重采样，逐步定位与问题相关的证据。

### Stage 1：全局初步推理

- **帧采样**：以固定速率 $r_1 = 1.0$ fps 采样帧，帧数 $N_1 = \lfloor D \times r_1 \rfloor$；超过骨干模型视觉 token 预算时在时间线上进行均匀子采样。
- **置信度估计（logit margin）**：
  - 主模型（Qwen3-VL-8B-Instruct）对 $N_1$ 帧做整体推理，输出各候选选项的 logits $\{z_i\}$。
  - 通过温度缩放 softmax 归一化：$P_i = \frac{\exp(z_i/T)}{\sum_{j=1}^{N}\exp(z_j/T)}$，其中 $T=2.0$ 为经验选取的温度。
  - 定义 logit margin $M = P_{\text{top1}} - P_{\text{top2}}$。
  - 若 $M \geq \tau$（$\tau = 0.97$），直接输出 top-1 答案（提前退出）；否则进入 Stage 2。
  - 该方案无需额外训练控制器，置信度估计用的正是答案选择的 logits。
- **Stage 1 关闭思维链**（enable_thinking=False），保持低延迟；深度思维链推理保留给 Stage 2 的不确定样本。

### Stage 2：工具辅助细粒度推理

包含四个顺序组件：

1. **时间片段提议（Temporal Segment Proposal）**
   - 主 VLM 被提示识别可能包含关键证据的时间区间 $[t_s, t_e]$。
   - 引入**广度感知回退（Breadth-Aware Fallback）**：若提议窗口超过 1200 秒或占视频 20% 以上，判定问题为全局依赖型，直接回退到 Stage 1 答案 $A_1$。
   - 对有效提议进行视频裁剪，最短时长强制为 10 秒。

2. **局部证据验证（Local Evidence Verification）**
   - 使用轻量级 VLM（Qwen3-VL-4B-Instruct）作为语义验证器。
   - 采用**预算感知密集采样（Budget-Aware Dense Sampling）**：采样率 $r_2 = \text{clip}(N_{\text{budget}}/D_{\text{crop}}, r_{\min}, r_{\max})$，其中 $N_{\text{budget}}=512$，$r_{\min}=1.0$ fps，$r_{\max}=8.0$ fps；短片段获得高时间分辨率，长片段保持在 token 预算内。
   - 验证器回答二分 Yes/No 问题，若 $P_{\text{yes}} \geq \delta$（$\delta=0.60$）则接受该片段，进入最终推理；否则触发反射步骤。
   - 验证器得分会跨迭代累积，用于指导后续重采样。

3. **反射式时间搜索（Reflection-based Temporal Search）**
   - 片段被拒绝时，系统将此前尝试过的所有区间反馈给主 VLM，实现**时空排除（spatio-temporal exclusion）**，使其提出与已有区间不重叠的新区间。
   - 最多执行 $K=2$ 轮反射，即最多 3 次“裁剪-验证”循环；若均未找到相关片段，则回退到 Stage 1 缓存答案 $A_1$，不进行额外全视频推理。

4. **相关性引导重采样（Relevance-Guided Resampling, RGR）**
   - 核心思想：**帧密度编码的反馈**——将累积的验证器得分转换为片段级 fps 映射，通过重采样的视觉输入隐式携带搜索历史。
   - 对第 $k$ 次验证的区间，记录得分片段 $S^{(k)} = \{t_s^{(k)}, t_e^{(k)}, f^{(k)}\}$，其中 $f^{(k)} = \min(1.0, P_{\text{yes}}^{(k)} + f_{\min})$，$f_{\min}=0.4$ fps 保证即使高度无关的片段也有非零覆盖。
   - 收集所有时间断点 $B = \text{sort}(\bigcup_k \{t_s^{(k)}, t_e^{(k)}\})$，为每个子区间分配最近覆盖它的得分片段的帧率 $f_{[b_i, b_{i+1}]} = f^{(k^*)}$（$k^*$ 为覆盖该子区间的最新索引）。
   - 相邻同帧率子区间合并以减少碎片化；每个子区间的有效帧数为 $n_i = \lfloor \Delta_i \times f_i \rfloor$。
   - 反射提示的总帧数为：$N_{\text{reflect}} = \sum_{[b_i,b_{i+1}]\in P} \lfloor \Delta_i \times f_i \rfloor + \lfloor D_{\text{unexplored}} \times r_1 \rfloor$。
   - 已探索且低相关的区域被降采样，未探索区域保持基础速率覆盖，从而实现更有效的 token 分配。

5. **最终局部推理**：相关片段被接受后，主 VLM 对其密集采样帧执行最终推理，通过结构化解析（带单字母回退）提取答案。

### 无需训练的可扩展性（Training-Free Scaling）

- 构建控制骨干模型 **Qwen3-VL-SFT**：在 LLaMA-Factory 框架下，用仅包含无工具 CoT 数据（LongVideo-Reason CoT、Video-R1 CoT、图像 CoT 指令数据，约 228.8K 条）对 Qwen3-VL-8B-Instruct 微调 1 个 epoch。
- 关键验证目标：(1) CADER 无需工具增强监督即可达到竞争性性能；(2) 骨干推理能力提升时，CADER 性能同步提升，无需重训任何工具使用策略。

## 6. 论文的主要结论与发现

1. **选择性工具调用优于统一工具调用**：统一将每个样本送入 Stage 2 反而降低精度（VMME 60.1→59.0），支持“按样本难度分配计算”的主旨。
2. **置信度信号可靠**：logit margin 与 Stage 1 准确率在 5 个基准上均呈单调递增，说明其可作为可信的路由信号，且无需额外模型调用。
3. **验证器是关键组件**：去掉验证器导致最大的性能下降（VMME -3.8，LVB -6.6），说明缺乏相关性检查会向主模型喂入无关视觉内容。
4. **RGR 有效**：在反射预算匹配下，RGR 相比均匀重采样带来稳定增益，证明帧密度编码反馈能改善重采样效率。
5. **无需工具增强训练的可行路径**：CADER 叠加仅经过无工具 CoT 监督的骨干即达到与 LongVT 等专用框架竞争的性能，表明推理期自适应计算与推理导向监督具有互补性。
6. **35%+ 样本可提前退出**：多数基准上超过 40% 的样本可在 Stage 1 直接回答，避免了不必要的工具流水线开销。

## 7. 优点

- **核心创新清晰且实用**：将“是否调用工具”提升为样本级决策，与现有“如何调用工具”的研究形成互补；置信度门槛 $\tau=0.97$ 和验证阈值 $\delta=0.60$ 跨基准保持一致，无需调参。
- **真正无需训练（training-free）**：不依赖任何工具使用的 SFT 数据或强化学习策略，可直接部署在任意改进的骨干模型上，具有极高的工程迁移性。
- **闭环反馈设计**：验证器得分经 RGR 编码为帧密度而非文本反馈，灵巧地解决“搜索历史如何影响后续提议”的问题，避免额外 token 开销。
- **两段式计算分配

（承上）两段式计算分配在简单与困难样本之间的动态切换，使计算预算随问题复杂度自适应缩放，符合实际长视频问答系统的部署需求。

## 8. 缺点与局限性

- **置信度阈值的经验性设定**：$\tau=0.97$ 与 $\delta=0.60$ 虽在实验中表现稳健，但论文未给出阈值的敏感性分析或自适应校准机制，在不同视频域或骨干模型下，最优阈值可能漂移。
- **对主干模型能力的依赖**：CADER 的 Stage 1 置信度估计和 Stage 2 时间片段提议均依赖主 VLM 的固有语义理解与时间感知能力，若骨干模型本身缺乏时间推理基础（如未在视频数据上充分预训练），路由信号和提议质量都会退化。
- **验证器与主模型间的能力错配**：4B 验证器的相关性判断可能不如 8B 主模型准确，尤其在需要复杂语义推理的高难度样本上，验证器可能错误拒绝相关片段（假阴性），导致不必要的反射轮次或最终回退到全局答案。论文未对这部分误差做量化。
- **最长视频适应性有限**：对超过骨干 token 预算的长视频，Stage 1 通过均匀子采样降帧，可能遗漏关键事件；Stage 2 的反射搜索虽能缓解，但对 3 小时以上的极端长视频，原始采样率 $r_1=1.0$ fps 带来的帧数仍会超出多数骨干的视觉 token 预算，需进一步工程优化。
- **缺乏对失败案例的系统分析**：论文未提供 Stage 2 回退后仍答错的样本的误差分类（如时间定位错误、验证器误判、推理幻觉等），无法明确指示下一阶段的改进方向。
- **并行与多 GPU 扩展性未讨论**：8 卡环境下未说明是按视频并行、按工具并行还是模型并行；若部署于单卡环境，延迟与显存占用可能成为瓶颈。

## 9. 个人见解与总体评价

CADER 的贡献在于提出了一个**计算分配的范式转变**——从“所有样本都走相同工具流水线”转向“根据样本难度决定是否调用工具”。这一思路在 LLM 推理领域（如 speculative decoding、early-exit Transformer）已有先例，但在长视频理解中尚属首次系统化实现，且其无需训练的特性使它在快速演进的骨干模型生态中具有显著的生命周期优势。

尤其值得注意的是 RGR 的设计——将验证器得分编码为重采样帧密度，本质上是一种**概率性的、隐式的记忆机制**：搜索历史不通过文本 token 传递给主模型，而是通过视觉输入的分布密度来影响后续推理。这避免了长上下文工具记录的 token 开销，同时保留了搜索历史的结构化影响，是一个优雅且低成本的工程方案。

从客观角度看，该工作的实验设计是扎实的，但证据链仍存在两个未完全闭合的环节：其一，消融实验只在 2 个基准上进行，而触发率分析揭示了不同基准间 Stage 2 触发率的显著差异（45.4%～78.6%），这意味着在未做消融的基准上（如 MLVU）各组件（尤其是验证器和 RGR）的相对贡献可能有所不同；其二，论文声称“无需训练”具有通用性，但控制实验的 SFT 骨干是在特定数据组合下训练的，若骨干更换为强化学习微调（如 Video-R1 类）或更大规模的模型，CADER 的阈值和采样参数是否需要重新调整仍是未知。

总体而言，CADER 是一个**设计精巧、动机明确、实验可复现**的自适应长视频推理框架。它的核心价值不在于某一单项技术的突破，而在于提出了一条清晰的工程路径：在骨干模型持续迭代的背景下，通过推理期的置信度路由实现计算资源的按需分配。该思想具有跨模态迁移的潜力（如长文档理解、长音频问答），是长视频理解从“全量处理”走向“选择性精处理”的一个里程碑式尝试。
